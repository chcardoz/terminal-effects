# Third-party assets

The interface icons in `assets/icons/` are selected, unmodified SVG assets from
[Lucide](https://github.com/lucide-icons/lucide), commit
`33a44aa8b0b43d9b0ed14eb08860a1b5550a1573`.

Lucide is copyright Lucide Contributors and is distributed under the ISC
license. A copy of that license is included at `assets/icons/LICENSE`.

The optional managed terminal renderer is
[terminal-browser](https://github.com/zenbu-labs/terminal-browser), copyright
Zenbu Labs, Inc., distributed under the MIT license. Terminal Effects downloads
the pinned `v0.5.8` release on first use and verifies its published SHA-256 hash;
the runtime is not stored in this repository.
